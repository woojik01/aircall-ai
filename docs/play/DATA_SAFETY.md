# 데이터 보안 양식 작성 근거

현재 코드에서 확인한 전송 경로를 정리한 작성 자료입니다. 사용자가 선택할 수 있는 **모든 모드**와 SDK를 포함해 최종 양식을 작성합니다. 로컬 모드가 있다고 전체 앱을 “데이터를 수집하지 않음”으로 제출하지 않습니다. 수집 정의에는 개발자 자신의 서버가 아닌 외부 서버로 전송하는 경우도 포함됩니다.

| 경로 | 확인한 데이터 | 검토할 데이터 유형 | 목적·선택 |
| --- | --- | --- | --- |
| Cloud API | 사용자 입력·대화 이력·답변 생성에 필요한 도구 결과, 인증 API 키 | 기타 앱 내 메시지, 기타 사용자 생성 콘텐츠; 내용에 포함된 개인정보·파일 등 | 앱 기능, 클라우드 선택 및 안내 동의 |
| Android 음성 서비스 | 마이크 음성·인식 텍스트·음성 출력 텍스트 | 음성 또는 소리 녹음, 기타 앱 내 메시지 | 앱 기능, 통화 선택 및 권한·고지 승인 |
| Gmail | 수신 주소·메일 제목·본문, 인증 토큰 | 이메일, 이메일 주소 및 메일에 포함한 데이터 | 앱 기능, 계정 승인 및 발송 작업 승인 |
| Google Calendar | 일정 제목·시작/종료 시간·설명, 인증 토큰 | 캘린더 일정 및 일정에 넣은 데이터 | 앱 기능, 계정 승인 및 조회/등록 |
| GitHub | 저장소·파일 조회, Issue/PR 작성 데이터, 인증 토큰 | 파일 및 문서, 기타 사용자 생성 콘텐츠 및 입력한 개인정보 | 앱 기능, 계정 연결 및 쓰기 작업 승인 |
| 서비스 문의 이메일 | 사용자가 메일 앱에서 직접 작성·전송하는 내용 | 앱은 대화·AI 응답·인증정보·기기 정보를 자동 첨부하지 않음 |
| 모델 다운로드 | HTTPS 다운로드 요청·파일 정보 | 모델은 사용자 파일이 아니지만 제공 서버의 요청 메타데이터와 SDK 동작 확인 | 앱 기능, 사용자 다운로드 선택 |
| 기기 전용 기록 | 채팅·메모·설정·인증정보 | 기기에만 머무는 데이터는 전송된 데이터와 구분 | 외부 기능에서 보내면 위 전송 경로에 포함 |

## 확인 항목

- **수집/공유는 다른 문항입니다.** 서비스 제공자 처리, 사용자 요청에 따른 전송 또는 충분한 고지·동의 등 공유 예외는 실제 처리 관계와 UI에 따라 판단합니다. 수집 문항까지 자동으로 “없음”으로 바꾸지 않습니다.
- **임시 처리라고 추정하지 않습니다.** AI 서버·음성 제공자가 로그나 내용을 남기는지 확인되지 않았다면 메모리에서만 처리한다고 선언하지 않습니다.
- **전송 암호화:** 앱 자체 요청은 HTTPS로 제한했습니다. 시스템 음성 서비스와 모든 SDK의 전송 기준도 공식 설명과 맞춰 확인합니다.
- **삭제:** 기기 데이터 전체 삭제가 가능합니다. 외부 서비스 데이터는 해당 서비스 절차를 이용합니다.
- **계정:** 자체 AirCall 서버 계정·프로필·사용자 ID를 만들지 않습니다. Google·GitHub는 기존 계정의 도구 접근 승인입니다. 이후 자체 계정을 추가하면 앱 내부/외부 계정 삭제 절차도 구현해야 합니다.
- **SDK:** `com.google.android.gms:play-services-auth:21.6.0`의 공식 공개 자료와 실제 사용하는 API의 데이터 처리를 검토합니다. 앱이 광고 ID나 분석 이벤트를 직접 요청하지 않는다는 이유만으로 SDK의 처리까지 없다고 선언하지 않습니다.
- **AI 제공자:** 기본 Groq 외에 다른 HTTPS 서버를 설정할 수 있습니다. 지원하는 전송 기능을 기준으로 양식·정책을 작성하고 제공자를 선택한다는 사실을 알립니다.
- **보관:** 기기 데이터는 사용자가 삭제할 때까지 보관합니다. 문의 메일은 공개 정책에 따라 운영자가 접수일부터 최대 30일 안에 메일함·휴지통에서 영구 삭제해야 합니다. 자동 신고 서버나 서버 보관기간 변수는 사용하지 않습니다. 외부 AI·음성·도구 제공자의 보관은 각 서비스 정책을 확인합니다.

최종 표시는 SDK/제공자의 처리 내용을 검토한 뒤 제출합니다.
