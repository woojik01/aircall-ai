1. 기능과 데이터 처리

기능처리하는 데이터와 목적저장·전송
텍스트 대화·기기 메모대화 기록, 채팅방 이름, 메모와 앱 설정을 대화와 메모 기능 제공에 사용합니다.앱 전용 기기 저장 영역에 보관합니다. 대화 기록과 인증정보는 Android Keystore를 이용해 암호화합니다. 일반 설정, 메모와 모델 파일 전체가 암호화되는 것은 아닙니다.
로컬 AI다운로드한 모델로 기기에서 응답을 생성합니다.AI 추론을 위해 대화 텍스트를 외부 AI 서버로 전송하지 않습니다. Hugging Face 등 모델 제공 서버의 모델 파일을 다운로드할 때 인터넷이 필요하며 서버는 연결에 필요한 네트워크 정보를 처리할 수 있습니다.
클라우드 AI대화 텍스트·대화 이력과 답변 생성에 필요한 도구 결과를 사용자가 설정한 AI 제공자(기본 설정: Groq)에 전송합니다.HTTPS를 사용합니다. API 키는 기기에 암호화해 저장하고 선택한 서버의 요청 인증에 사용합니다. 클라우드 전송 전에 안내와 동의를 받습니다. 해당 제공자의 데이터 보관·삭제·국외 처리 기준이 적용됩니다.
음성 대화마이크로 음성을 인식하고 AI 응답을 음성으로 출력합니다.Android 음성 인식·출력 서비스를 사용합니다. 서비스와 언어 설정에 따라 음성과 텍스트가 제공자에게 전송될 수 있습니다. 로컬 AI 선택만으로 음성 서비스까지 오프라인인 것은 아닙니다. 앱은 원본 음성 녹음 파일을 자체 저장하지 않습니다. 인식된 텍스트는 대화 기록에 포함됩니다.
Google·GitHub 도구 연결사용자가 승인한 OAuth 토큰과 도구 요청을 사용합니다. GitHub 저장소·파일 조회와 Issue/PR 생성, Gmail 메일 발송, Google 기본 캘린더 일정 조회·등록에 사용합니다.토큰은 기기에 암호화 저장하며 요청 인증을 위해 해당 서비스에 전송합니다. 메일 주소·제목·본문, 일정 제목·시간, 저장소·파일·Issue·PR 요청 데이터가 기능 실행 시 해당 서비스로 전달됩니다. 도구 결과는 응답 생성에 사용되며 클라우드 모드에서는 AI 제공자에게도 전달될 수 있습니다.
신고·문의사용자가 작성한 신고 내용, 임의의 신고 접수 번호, 앱 버전과 Android API 버전을 오류 해결·안전성 개선·문의 처리에 사용합니다. 선택한 AI 응답은 사용자가 명시적으로 함께 보내기를 선택할 때만 포함됩니다.운영자의 HTTPS 신고 접수 서비스(접수 주소)로 전송하고 비공개 Google Apps Script/Google Sheets에 저장합니다. 전체 대화, API 키, OAuth 토큰, 지속적인 기기 식별자를 자동 첨부하지 않습니다. 사용자가 입력한 내용에는 개인정보가 포함될 수 있으므로 전송 전에 지워 주세요.

2. 권한과 선택

마이크 권한은 음성 대화 시작 시 요청합니다. 음성 서비스를 통한 데이터 사용을 안내하고 동의를 받습니다. 사용자가 시작한 통화는 다른 앱을 사용하거나 화면이 꺼진 동안에도 마이크를 사용할 수 있으며 지속 알림에서 일시정지·종료할 수 있습니다. 알림 권한은 통화·다운로드·작업 결과 안내를 위해 요청하며, 다른 앱 위에 표시 권한은 선택적인 통화 제어 기능을 위해 사용합니다.

텍스트 대화와 기기 메모에는 Google·GitHub 로그인이 필수가 아닙니다. 로컬 모델에는 다운로드, 충분한 저장공간·메모리 및 호환 기기가 필요합니다. 클라우드와 외부 도구, 음성 서비스의 일부 기능에는 인터넷이 필요합니다. 외부 서비스 쓰기 작업은 앱의 승인 절차를 따르며 저장된 승인은 설정에서 해제할 수 있습니다.

3. 보관과 삭제

기기 데이터는 사용자가 삭제할 때까지 앱 저장 영역에 보관합니다. 채팅방 삭제, API 키 삭제, 계정 연결 해제, 모델 삭제 기능으로 개별 데이터를 지울 수 있습니다. 설정 → 개인정보 → 이 기기의 앱 데이터 모두 삭제를 선택하면 채팅·메모·API 키·토큰·설정·모델을 지우고 앱을 초기화합니다. 앱 삭제로도 해당 앱의 기기 저장 영역을 제거할 수 있습니다.

개발자에게 접수된 신고는 접수일로부터 {{AIRCALL_REPORT_RETENTION_DAYS}}일이 지난 뒤 매일 수행하는 정리 작업에서 삭제합니다. 정리 시점에 따라 최대 약 하루의 지연이 있을 수 있습니다. 더 빠른 삭제는 앱 안의 개인정보 문의 또는 위 문의 이메일에 접수 번호를 적어 요청할 수 있습니다. 운영 플랫폼 자체의 로그·백업 보관은 해당 제공자의 정책을 따릅니다. 운영자는 신고를 공개 게시하지 않습니다.

AirCall AI 자체의 서버 계정을 생성하지 않습니다. Google·GitHub 연결 해제는 기기의 연결 토큰을 삭제하며 해당 서비스 계정 자체를 삭제하지 않습니다. 서비스 계정 설정에서 AirCall AI 접근 권한도 취소할 수 있습니다. 이미 발송한 메일·등록한 일정·생성한 Issue/PR·외부 AI 제공자에 전달한 데이터는 기기의 데이터 삭제로 지워지지 않으며 해당 서비스의 삭제 절차를 이용해야 합니다.

4. 보안·제삼자 서비스

앱은 평문 HTTP 연결을 허용하지 않으며 인증정보를 Android Keystore 기반으로 암호화 저장합니다. 광고 SDK와 자체 사용행동 분석·광고 추적 SDK를 포함하지 않습니다. 신고 접수와 사용자가 선택한 클라우드·모델 다운로드·음성·계정 서비스는 각 제공자의 정책과 서버 운영 지역에 따라 데이터를 처리합니다. 선택한 서비스의 개인정보 정책도 확인해 주세요. HTTPS는 전송 암호화이며 외부 서비스가 내용을 처리할 수 없는 종단간 암호화를 의미하지 않습니다.

5. AI 사용과 이용자 요청

AI 응답은 틀릴 수 있습니다. 의료·법률·금융 등 중요한 판단에는 별도 확인이 필요합니다. 아동 성착취, 성폭력, 불법 위해 행위와 기만을 돕는 용도로 사용할 수 없습니다. 앱은 안전 지침과 일부 규칙 검사를 적용하며 부적절한 응답을 앱 안에서 신고할 수 있습니다. 신고는 검토하여 안전 기능과 앱 개선에 활용합니다.

개인정보 처리에 관한 문의·삭제 요청은 앱 안의 문의 및 신고 또는 {{AIRCALL_SUPPORT_EMAIL}}로 할 수 있습니다. 자신의 권한이 없는 제삼자의 개인정보를 신고에 첨부하지 마세요. 이 앱은 어린이를 대상으로 설계된 서비스가 아니며 Google Play의 실제 콘텐츠 등급과 대상 연령 안내를 따라 주세요.

6. 정책 변경

데이터 사용 범위가 바뀌면 앱 안내와 이 페이지를 갱신합니다. 새로운 전송 주소나 중요한 처리 변경에 필요한 동의는 해당 기능 사용 전에 다시 안내합니다.
