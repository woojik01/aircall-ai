# 심사 접근 안내와 실제 검증

## 앱 액세스 안내 초안

첫 실행에서 만 14세 이상 대상 안내를 확인한 뒤 기본 채팅 화면을 표시하며 자체 계정 생성이 필요하지 않습니다. 메뉴 → 설정에서 개인정보 안내와 신고 기능을 볼 수 있습니다.

1. 설정 → AI 및 모델 → 로컬 모델 관리에서 Gemma 4 E2B를 다운로드하고 적용합니다. 현재 파일은 약 2.59 GB입니다. 저장공간·RAM·제공 서버 접근이 필요하며 호환 ARM64 기기를 사용합니다.
2. 채팅 화면에서 메시지를 보내고 답변을 확인합니다. 로컬 AI 추론은 기기에서 처리합니다.
3. 음성 화면에서 데이터 안내에 동의하고 마이크를 허용한 후 통화를 시작합니다.
4. 응답 신고 버튼에서 내용을 적고 응답 첨부 여부를 선택해 전송합니다. 실제 접수 번호가 표시되어야 합니다.

클라우드와 외부 도구에는 제공자 API·외부 계정 승인이 필요합니다. 심사에 해당 경로가 필요한 경우 **Play Console의 비공개 앱 액세스 안내에만** 안전한 테스트 정보와 접근 방법을 입력합니다. 개인 API 키·메일·비밀번호를 공개하지 않습니다. 모델 다운로드나 외부 API가 준비되지 않은 경우 “아무 설정 없이 모든 기능 사용 가능”이라고 적지 않습니다.

## FGS 선언 자료

| 타입 | 기능 | 시작·종료 | 제출 영상 |
| --- | --- | --- | --- |
| `microphone` | AI 음성 대화의 음성 인식 | 통화 시작·마이크 승인, 통화/알림 일시정지·종료 | 시작 → 마이크 표시 → 홈 화면 → 알림 종료 |
| `dataSync` | 선택한 로컬 모델 다운로드 | 다운로드 버튼, 완료·실패·취소·시간 제한 종료 | 다운로드 → 화면 밖 진행 알림 → 취소 |

Android 15+의 dataSync 시간 제한 콜백을 처리합니다. 부팅 자동 시작이나 권한 제한 우회는 하지 않습니다. 전체 화면 인텐트, 정확한 알람, SMS·통화기록·연락처·전체 파일 접근 권한은 추가하지 않습니다.

## 실기/Play 테스트

- [ ] **Play 내부 테스트로 설치**한 정식 앱의 최소 연령 안내·첫 실행·모델 다운로드·텍스트/음성 대화. 만 14세 미만이 나가기를 선택하면 종료되고 전송을 시작하지 않음.
- [ ] 최소 Android 8/API 26, Android 15/16, 회전·키보드·글꼴 확대·시스템 바·테마.
- [ ] ARM64의 CPU/GPU와 16 KB 기기에서 실제 모델 실행. 정렬 검사를 런타임 실행으로 대체하지 않음.
- [ ] 클라우드/음성 안내 취소 시 전송·마이크 시작 없음, AI 주소 변경 시 재동의.
- [ ] 로그인 없는 신고, 시트 저장·접수 번호 일치, 응답 첨부 기본 해제·수정·제외.
- [ ] 오프라인·타임아웃·HTML 로그인 응답·서버 실패 시 거짓 완료 없음, 동일 내용 재시도 중복 저장 없음.
- [ ] 신고 보관 정리 트리거와 접수 번호별 삭제.
- [ ] Google이 메일 발송·일정 권한만 요청하고 사서함 읽기/수정 권한을 요청하지 않음. Play 인증서로 로그인.
- [ ] 메모·메일·일정·GitHub 쓰기 승인/거부, 실제 결과, 결과 알림.
- [ ] 마이크·알림·오버레이 권한 거부에도 기본 텍스트 화면 접근.
- [ ] 통화·다운로드 알림 제어, 장시간 서비스 종료, 프로세스 종료 후 안내.
- [ ] **이전 Play 버전 위 높은 versionCode 업데이트**에서 설정·대화·메모·토큰·모델 보존. 개발용 CI 업데이트와 구분.
- [ ] 전체 데이터 삭제 → 종료 → 재시작 초기 상태. 외부로 전송한 데이터는 별도 삭제가 필요하다는 안내와 일치.
- [ ] 실제 모델 유해 요청·우회·프롬프트 주입·거짓 완료 검사. 안전 프롬프트·좁은 규칙 필터의 한계 확인.
- [ ] 비공개 테스트 참여·피드백·수정 기록, 사전 출시 보고서, 실제 스크린샷.

자동 검증은 JVM 테스트, 수신기 모의 테스트, 설정 검사, release Lint/R8, APK/AAB 서명·구조·API·ARM64·16 KB 정렬, 개발용 앱 업데이트 데이터 보존입니다. 실제 서버·Google 심사·실기 음성·전체 모델 추론·Play 업데이트는 위 목록으로 확인합니다.
