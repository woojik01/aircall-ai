# 스토어 문구 초안

공개 표시 이름과 문의 이메일은 실제 운영자가 정한 값으로 입력합니다. 콘텐츠 등급은 IARC 답변으로 정합니다.

## 앱 이름 (30자 이내)

AirCall AI

## 짧은 설명 (80자 이내)

텍스트와 음성으로 대화하는 AI. 로컬 모델과 나만의 클라우드 API를 선택하세요.

## 자세한 설명

AirCall AI는 Android에서 텍스트와 음성으로 대화할 수 있는 AI 앱입니다.

로컬 모델을 다운로드하여 기기에서 AI 응답을 생성하거나, 자신의 API 키로 클라우드 AI에 연결할 수 있습니다. 채팅방을 만들고 이름을 바꾸거나 삭제하며 대화를 관리하세요. 라이트·다크·시스템 테마를 선택할 수 있습니다.

필요할 때 Google과 GitHub 계정을 연결해 메일을 보내고, 기본 캘린더의 일정을 조회·등록하거나 GitHub 저장소와 파일을 조회하고 Issue·PR을 만들 수 있습니다. 기기 메모는 로그인 없이 사용할 수 있습니다. 외부 데이터를 변경하는 작업은 앱의 승인 절차를 따릅니다.

진행 중인 음성 대화와 모델 다운로드는 알림에서 제어할 수 있습니다. 개인정보 화면에서 데이터 사용을 확인하거나 기기 데이터를 삭제할 수 있습니다.

이용 전 확인해 주세요.
• 앱은 무료이며 광고와 앱 내 결제가 없습니다.
• 로컬 모델은 별도 다운로드가 필요하며 충분한 저장공간과 메모리가 필요합니다. 실행 가능 여부와 속도는 기기에 따라 다릅니다.
• 로컬 AI의 텍스트 응답 생성은 기기에서 처리됩니다. 음성 인식·출력, 모델 다운로드, 클라우드 AI와 외부 도구는 별도로 인터넷을 사용할 수 있습니다.
• 클라우드 기능에는 사용자가 설정한 API 키가 필요하며 해당 제공자의 요금·이용 조건이 적용될 수 있습니다.
• Google·GitHub 연결 없이도 기본 대화와 기기 메모를 사용할 수 있습니다. 연결이 필요한 기능은 해당 서비스의 승인이 필요합니다.
• AI 답변은 틀릴 수 있으므로 중요한 정보와 외부 작업의 실제 결과를 확인하세요.

## 이미지

아이콘은 512×512 PNG, 최대 1,024 KB입니다. 그래픽 이미지는 1,024×500 PNG/JPEG, 알파 없음입니다. 전화기 스크린샷은 최소 2장, 최소 변 320px·최대 변 3,840px, 큰 변이 작은 변의 두 배 이하로 준비합니다. 제출할 정식 앱의 실제 화면에서 촬영하고 이름·메일·토큰·개인 대화를 지웁니다.

권장 화면은 텍스트 대화, 음성 대화, 로컬 모델 관리, 도구 및 계정, 테마 설정입니다. 실행하지 않은 도구의 성공 화면이나 앱에 없는 UI를 만들지 않습니다. 가격·순위·수상·스토어 배지 같은 문구를 아이콘에 넣지 않습니다. 아이콘과 시각 자산의 사용 권한은 운영자가 확인합니다.
