# AirCall AI 사용 경험 개선

2026-10-10 개발 변경. 기존 공개 APK 0.4.1 (30007)에 포함된 기능을 뜻하지 않습니다.

## 구현 순서

1. 텍스트는 자세한 설명·기본 Markdown을, 음성은 짧은 구어체를 사용합니다. 로컬 출력 한도는 텍스트 1024토큰·음성 256토큰입니다.
2. AI 설정에서 실행 방식과 시작 절차를 안내합니다. 로컬 화면은 RAM·저장 공간으로 첫 모델을 추천합니다. 클라우드 연결 테스트는 키와 고정 테스트 문장의 전송 확인을 받으며 대화 기록을 전송하지 않습니다.
3. 지원하는 클라우드 API는 SSE 응답을 실시간 표시합니다. 일반 대화는 완성된 문장부터 읽고, 도구 작업은 실행·검증을 마친 최종 결과를 읽습니다. API 미지원 시 실시간 응답을 끌 수 있습니다. 음성 인식 중간 결과 표시는 Android 서비스 지원에 따라 달라집니다. 끼어들기는 화면 버튼으로 수행합니다.
4. 로컬 E2B는 2800바이트·E4B는 6000바이트 입력 예산을 사용합니다. E4B 엔진 문맥은 8192토큰입니다. 오래된 대화는 역할을 표시한 짧은 발췌로 남깁니다. 추론으로 생성한 장기 요약은 아니며 모든 사실의 기억을 보장하지 않습니다. 별도 기억은 사용자 직접 관리·최대 150자·기기 암호화 저장입니다.
5. 구조화된 도구 호출은 지원하는 클라우드 API에서 선택적으로 활성화합니다. 기존 호출도 같은 검증·일회 승인 계층을 사용합니다. 승인창에서 인자만 수정할 수 있고, 도구 종류·작업을 바꾸거나 이중 탭으로 중복 실행할 수 없습니다. 최종 승인 내용을 AI 결과에도 반영합니다.
6. 암호화 백업과 일반 JSON을 저장·가져옵니다. 기존 자료를 삭제하지 않으며 동일한 자료를 중복 추가하지 않습니다. 변경 작업을 시도한 뒤 실패한 요청은 자동 재시도하지 않습니다. 직접 설치·원스토어·Google Play의 업데이트 이동 경로를 분리합니다.

## 데이터 및 호환성

- 백업: 대화·메모·사용자 기억·일반 설정. 키·토큰·승인·모델 파일은 제외합니다.
- 암호화: PBKDF2-HMAC-SHA256 210000회, 무작위 16바이트 salt, AES-256-GCM과 무작위 12바이트 nonce. 비밀번호는 저장하지 않습니다.
- 가져오기: 복호화·형식·크기·역할·설정을 먼저 검사합니다. SYSTEM 메시지는 가져올 수 없습니다. 채팅은 별도 방으로 추가합니다. 기억은 현재 값이 없을 때 복원하며 일반 설정은 사용자 선택입니다.
- 파일·대화 저장 크기는 8MiB로 제한합니다. 여러 저장소의 가져오기는 단일 트랜잭션이 아닙니다. 저장 중 실패하면 일부 자료가 추가될 수 있으나 기존 자료를 지우지 않으며 같은 파일을 다시 가져오면 중복을 건너뜁니다.
- 다운로드: HTTPS 리다이렉트와 Range 사용. 범위를 확인하고 전체 파일을 해시 검증합니다. Range 미지원이면 새로 다운로드합니다. 부분 파일은 일시중지·네트워크 중단 후 남으며 삭제 버튼으로 정리할 수 있습니다.
- 텍스트 응답의 기본 Markdown 표시는 제목·목록·굵은 글씨·코드·표를 대상으로 합니다. HTML을 실행하지 않습니다.
- 클라우드 모드의 기억·도구 결과 전송은 기존 데이터 사용 동의 범위에 포함됩니다. 메일 및 GitHub 변경 작업은 계속 별도 승인을 받습니다.

## 검증 범위

JVM 단위 검사에 답변 방식, 스트림 종료·취소·문장 재생, native 도구 호출 왕복, 편집된 승인,
다운로드 이어받기·해시 검증, 문맥 예산·발췌, 백업 변조·다른 비밀번호·반복 가져오기·재시도 보호를 포함합니다.

Android 검사 `PortableBackupTest`는 서로 다른 Android Keystore 키로 대화 저장소를 만들고
비밀번호 백업으로 이전해 내용을 복원합니다. CI의 API 35·36 업데이트 검사에 연결합니다.

실제 사용자의 클라우드 API·Google 로그인·블루투스 오디오·로컬 모델 속도와 발열은 실기 확인이 필요합니다.
