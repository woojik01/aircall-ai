# PRD-07 — 통화형 UI 및 사용자 경험

## 목표

앱을 일반적인 채팅 앱이 아니라 실제 통화에 가까운 음성 대화 앱으로 완성한다.

## 메인 통화 화면

핵심 요소:
- AI 상태 표시
- 현재 대화 상대/AI 이름
- 음성 입력 상태
- 음성 출력 상태
- 음소거
- 일시정지
- 통화 종료

불필요한 UI 요소는 최소화한다.

## 상태 표현

사용자가 현재 AI가 무엇을 하고 있는지 즉시 알 수 있어야 한다.

예:
```
Listening
Thinking
Speaking
Paused
Muted
Offline
Error
```

## 플로팅/백그라운드 제어

다른 앱을 사용할 때:
- 시스템 알림을 기본 제어 수단으로 사용
- 필요한 경우 사용자에게 오버레이 권한을 요청하고 작은 컨트롤 UI 제공
- 오버레이는 앱의 핵심 기능을 방해하지 않아야 한다.

## 접근성

- 버튼 크기 충분히 확보
- 음성 상태를 색상만으로 구분하지 않음
- Talk/End/Mute 기능을 명확한 텍스트 또는 접근성 라벨로 제공
- 시스템 글자 크기 확대를 고려

## 완료 조건

- 통화 화면 완성
- 상태 전환 시 UI 정확성
- 백그라운드 알림 제어
- 오버레이를 사용하는 경우 권한 거부 상태도 정상 동작
- 화면 회전/복귀 테스트
- 실제 기기 테스트
