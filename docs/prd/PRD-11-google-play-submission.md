# PRD-11: Google Play 첫 제출 준비

## 결정

2026-10-04 사용자 확인: 무료·광고 없음, 청소년·성인(만 14세 이상), 한국 우선, 개발자 계정 없음, 공개 이름/정책 URL 미정. 현재 개인 API 키·외부 연동 토큰의 기기 암호화 저장 구조를 유지한다.

2026-10-06 변경: AI 응답 신고와 HTTPS 접수 연결을 제거하고, 서비스 문의 메일은 woojik1220@gmail.com으로 통일한다.

## 사용자 흐름

1. 설치 후 로그인 없이 채팅·메모·설정에 접근한다.
2. 로컬 모델은 사용자 요청으로 다운로드·적용한다. 클라우드는 사용자의 HTTPS 주소와 API 키로 연결한다.
3. 클라우드 첫 요청 전 주소·전송 내용을 고지하고 승인받는다. 주소 변경은 새 동의를 요구한다.
4. 통화 전 음성 서비스 전송과 화면 밖 마이크 사용을 고지한다. 마이크 권한은 통화 시작 시 요청한다.
5. 설정에서 서비스 문의 이메일 버튼으로 메일 앱을 열고 사용자가 직접 작성·전송한다.
6. 개인정보 화면에서 공개 정책·연락처·외부 계정 해제·기기 데이터 삭제에 접근한다.

## 배포 흐름

`코드/모의 테스트 → Android Lint·JVM·R8 → 서명된 APK/AAB → bundletool 생성 APK 검사 → Play 내부 테스트 → 실제 기기·정책·OAuth·스토어 양식 → 비공개 테스트 → 프로덕션 신청`

릴리스는 공개 정보·HTTPS 정책·개인 키·기존 서명과 증가하는 versionCode를 검사한다. CI 테스트용 키는 배포하지 않는다. Play 업로드와 공개 출시는 자동 수행하지 않는다.

## 검증 조건

- 문의 버튼은 기기의 메일 앱을 열며, 전송 완료나 접수 완료를 앱에서 표시하지 않는다.
- 문의 메일에 대화·AI 응답·인증정보·기기 정보를 자동 첨부하지 않는다.
- 동의 전 클라우드/음성 기능을 시작하지 않는다. 전송 주소와 데이터 보안/정책 문구가 일치한다.
- API 36, 정식 앱 ID, 개인 서명, release 비디버그, ARM64·16 KB 정렬과 AAB 생성 APK 검사가 통과한다.
- Play에서 설치한 정식 앱의 업데이트·OAuth·모델·음성·시스템 바·권한 거부를 실제 확인한다.
- 운영자는 모델별 안전 테스트를 수행한다. 기본 프롬프트·정규식 검사만으로 완전한 콘텐츠 판별을 선언하지 않는다.

## 현재 외부 준비가 필요한 항목

계정, 공개 이름·연락처·정책 게시, 키 보관, Play 앱 서명/OAuth 검증, 대상 연령·국가·IARC·FGS·SDK 데이터 검토, 실제 스크린샷, 실기와 신규 개인 계정 테스트. [제출 안내](../play/README.md)에 절차와 공식 근거를 기록한다.
