# PRD-05 — 백그라운드 음성 대화 및 멀티태스킹

## 목표

사용자가 AirCall AI를 실행한 상태에서 다른 앱을 사용하거나 화면을 끈 상태에서도 음성 대화를 유지할 수 있도록 한다.

## Android 백그라운드 구조

기본 수단:
- Foreground Service
- 지속적인 알림
- 명확한 마이크 사용 표시
- 서비스 생명주기 관리

ConnectionService는 실제 Android 전화 통합이 필요한 경우에만 별도 검토한다. AI 음성 대화 자체를 위해 무조건 전화 프레임워크를 사용하지 않는다.

## Foreground Service 책임

- 음성 캡처
- 대화 세션 상태 유지
- TTS 상태 관리
- 세션 종료
- 시스템/사용자 종료 처리

UI가 Service 내부 로직에 직접 의존하지 않도록 Binder/Repository 등 명확한 상태 통로를 사용한다.

## 알림

알림에서 최소한:
- 대화 상태
- 음소거
- 일시정지/재개
- 종료

를 제공한다.

## 화면 꺼짐

- 화면이 꺼져도 서비스가 정상적으로 유지되어야 한다.
- 배터리 최적화 정책과 Android 버전에 따른 제한을 고려한다.
- 불필요한 CPU/네트워크 사용을 줄인다.

## 멀티태스킹

사용자가 다른 앱을 열어도 대화 세션이 유지된다.

예:
```
AirCall AI 대화
      ↓
GitHub 확인
      ↓
Calendar 확인
      ↓
메모 작성
      ↓
AirCall AI 계속 대화
```

## 완료 조건

- 다른 앱으로 전환 후 대화 유지
- 화면 OFF 후 테스트
- 알림에서 종료 가능
- 알림에서 음소거 가능
- 서비스 비정상 종료 복구
- 배터리/CPU 사용량 측정
- CI 통과
