# 원스토어 검증 경로 및 출시 전 실기 기록

자동 CI 검증과 실제 기기 결과를 별도로 기록합니다. 아래 항목은 아직 실기 통과를 선언하지 않습니다.

## 검증 담당자 참고

- AirCall AI 자체 계정·로그인 없이 시작할 수 있습니다. 첫 실행에서 만 14세 이상 안내를 확인합니다.
- 설정 → AI 및 모델에서 로컬 모델 다운로드·적용 또는 Cloud API 설정이 필요합니다.
- 로컬 모델 파일은 APK에 포함하지 않습니다. 다운로드 용량·기기 RAM은 모델 관리 화면에서 확인합니다.
- Google 연결에는 Google Play 서비스가 필요하며, GitHub·Google은 외부 도구의 선택 연결입니다.
- API 키가 필요한 검증에는 제한된 테스트 키를 별도 비공개 검증 참고 정보로 제공합니다.
  APK, GitHub 소스, 상품 설명, 스크린샷에는 키를 넣지 않습니다.
- 공개 사용자를 막는 Google 테스트 사용자 제한이 남아 있다면 Google 연동이 공개 준비된 것으로 표시하지 않습니다.
- 신고: 응답의 **응답 신고**, 설정 → 개인정보 → **앱 안에서 문의 및 신고**,
  설정 → 앱 정보 및 사용 안내 → **문의 및 AI 응답 신고**.
- 삭제: 메뉴의 채팅방 관리 → 삭제, 설정 → 도구 및 계정 → 연결 해제,
  설정 → 개인정보 → **이 기기의 앱 데이터 모두 삭제**.
- 업데이트: 설정 → 앱 정보 및 사용 안내 → **원스토어에서 업데이트 확인**.
- 앱 내 결제·구독·광고가 없습니다. APK는 ONEconsole에서 검증을 요청하며 자동 배포하지 않습니다.
