# 원스토어 검증 참고: 데이터와 권한

이 문서는 Google Play 데이터 보안 양식 대신 AirCall AI의 실제 데이터 흐름을 설명합니다.
ONEconsole의 개인정보·권한 질문은 최신 제출 APK와 게시한 정책을 기준으로 답합니다.

| 기능 | 데이터 / 저장 | 외부 전송 |
| --- | --- | --- |
| 채팅방 | 채팅·제목은 앱 전용 저장소에서 암호화 | Cloud 선택 시 대화·응답에 필요한 도구 결과를 사용자가 설정한 API에 전송 |
| 로컬 AI | 모델은 앱 전용 저장소. 모델 전체 암호화는 하지 않음 | 다운로드 서버와 통신. 모델 로컬 텍스트 추론은 AI 서버로 대화를 보내지 않음 |
| 자격증명 | API 키·OAuth 토큰은 Android Keystore 기반 암호화 | 선택한 API·외부 서비스 요청 인증에 사용 |
| 음성 | 인식된 텍스트는 채팅에 포함. 앱이 원본 녹음 파일을 자체 저장하지 않음 | Android 음성 서비스·언어 설정에 따라 음성·텍스트 전송 가능 |
| 메모·일반 설정 | 기기 전용 저장소. 전체 암호화 아님 | Notes 자체는 네트워크 사용 안 함 |
| GitHub | 연결 토큰·연결 상태 | 요청과 인증을 GitHub API에 전송, 도구 결과는 AI 응답 생성에 사용 |
| Gmail·Calendar | 연결 토큰·연결 상태 | 발송 메일·일정 요청·토큰을 Google API에 전송, 도구 결과는 AI 응답 생성에 사용 |
| 서비스 문의 | 사용자가 메일 앱에서 직접 작성·전송 | woojik1220@gmail.com; 앱 정보 자동 첨부 없음 |

| Manifest 권한 | 목적 / 요청 시점 |
| --- | --- |
| INTERNET | Cloud·모델 다운로드·외부 로그인·도구 네트워크 |
| RECORD_AUDIO | 사용자가 음성 대화를 시작할 때 런타임 요청 |
| FOREGROUND_SERVICE / MICROPHONE | 사용자 시작 음성 세션의 지속 알림·백그라운드 마이크 |
| FOREGROUND_SERVICE_DATA_SYNC | 사용자가 시작한 모델 다운로드의 진행률·취소 알림 |
| WAKE_LOCK | 진행 중 세션의 기기 절전 대응 |
| POST_NOTIFICATIONS | 작업 결과·통화·모델 다운로드 알림, 거부 시 앱에서 결과 확인 |
| SYSTEM_ALERT_WINDOW | 사용자가 선택해 허용한 플로팅 통화 컨트롤. 기본 대화에 필수 아님 |

휴대전화·SMS·주소록·기기 캘린더·위치·모든 파일 접근 권한은 선언하지 않습니다.
Google 캘린더는 기기 캘린더 권한 대신 Google OAuth와 Calendar API로 연결합니다.
음성 인식과 TTS queries 선언은 서비스를 찾기 위한 선언이며 새 개인정보 권한이 아닙니다.

권한 거부·계정 미연결 때문에 앱 전체 사용을 막지 않습니다.
클라우드·음성 전송은 기능 사용 전 고지와 동의를 받습니다. 개인정보 화면에서 계정 연결 해제와
기기 데이터 삭제 방법을 확인할 수 있습니다. 앱 데이터 모두 삭제는 확인 후 앱을 초기화하고 종료합니다.
