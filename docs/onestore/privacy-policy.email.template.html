항목·목적: 사용자가 입력한 대화, AI 응답, 채팅방 이름을 대화 기능과 기록 조회에 사용합니다. 음성 인식으로 얻은 텍스트도 대화에 포함됩니다.

저장·전송: 채팅방 이름과 대화 기록은 앱 전용 기기 저장 영역에 암호화해 저장합니다. 로컬 텍스트 추론에는 외부 AI 서버로 전송하지 않습니다. 클라우드 모드에서는 대화 이력과 응답에 필요한 도구 결과를 설정한 API로 전송합니다.

저장·전송: 앱 전용 기기 저장 영역에 저장합니다. 메모와 일반 설정 전체를 암호화하지는 않습니다. 메모 도구 자체는 네트워크를 사용하지 않지만, 검색·조회한 메모가 AI의 응답에 사용될 수 있으며 클라우드 모드에서는 해당 AI 제공자에게 전달될 수 있습니다.

로컬 AI와 모델 다운로드

항목·목적: 선택한 모델과 대화 텍스트를 기기에서 응답을 생성하는 데 사용합니다.

저장·전송: 모델 파일은 앱 전용 저장 영역에 저장하며 전체 파일을 암호화하지는 않습니다. Hugging Face와 연결된 모델 배포 서버에서 모델을 다운로드합니다. 다운로드 서버는 IP 주소 등 통신에 필요한 네트워크 정보를 처리할 수 있습니다. 모델을 받은 뒤 수행하는 로컬 AI 텍스트 추론은 대화를 외부 AI 서버로 보내지 않습니다.

클라우드 AI와 API 키

항목·목적: 대화 텍스트·대화 이력·응답에 필요한 도구 결과, 선택한 모델 이름과 API 키를 응답 생성과 요청 인증에 사용합니다. 기본 클라우드 제공자는 Groq이며 사용자가 다른 호환 HTTPS API로 변경할 수 있습니다.

저장·전송: API 키는 기기에 암호화해 저장합니다. 사용자가 해당 주소의 전송 안내에 동의한 뒤 앱이 선택한 API를 직접 호출합니다. 개발자의 별도 AI 중계 서버를 거치지 않습니다. 해당 서버는 대화와 인증용 키를 처리합니다.

음성 대화

항목·목적: 마이크 음성은 텍스트로 인식하고 AI 응답 텍스트는 음성으로 출력합니다.

저장·전송: Android 음성 인식과 TTS 서비스를 이용합니다. 선택된 서비스·언어·기기 설정에 따라 음성과 텍스트가 서비스 제공자의 서버에 전송될 수 있습니다. 로컬 AI를 선택해도 음성 서비스의 오프라인 동작을 보장하지 않습니다. 앱은 원본 음성 녹음 파일을 자체 저장하지 않습니다. 인식된 텍스트는 대화 기록에 저장됩니다.

Google·GitHub 계정과 도구

항목·목적: 사용자가 승인한 서비스의 인증 토큰과 연결 표시 정보, 도구 요청·결과를 사용합니다. GitHub에서는 저장소·파일 조회와 Issue/PR 생성, Google에서는 Gmail 메일 발송과 기본 캘린더 일정 조회·등록을 지원합니다.

저장·전송: 토큰과 저장되는 계정 표시 정보는 기기에 암호화해 저장합니다. 인증과 도구 실행에는 해당 제공자와 통신합니다. 수신 이메일 주소·메일 제목·본문, 일정 제목·시간, 저장소·파일·Issue/PR의 요청 데이터가 실행에 따라 해당 서비스로 전달됩니다. Google의 현재 구현은 단기 액세스 토큰을 사용하며 앱이 Google 새로고침 토큰을 보관하지 않습니다. Google 인증 권한은 Gmail 발송과 캘린더 이벤트이며 메일함 읽기 기능을 제공하지 않습니다.

도구의 조회 결과와 실행 결과는 AI 응답 생성에 사용되며 클라우드 모드에서는 설정한 AI 제공자에게도 전달될 수 있습니다. GitHub에 만든 공개 Issue/PR와 발송한 메일 등은 해당 서비스의 공개 범위와 수신자에 따라 다른 사람에게 보일 수 있습니다.

AI 응답 신고와 문의 이메일

3. 권한·동의·선택

  • 마이크 권한은 음성 대화를 시작할 때 요청합니다. 음성 서비스의 데이터 사용 안내와 동의를 확인합니다. 사용자가 시작한 음성 세션은 다른 앱을 쓰거나 화면이 꺼진 동안에도 계속될 수 있으며 알림 또는 앱에서 일시정지·종료할 수 있습니다.
  • 알림 권한은 통화, 모델 다운로드와 도구 작업 결과 안내에 사용합니다. 다른 앱 위에 표시 권한은 선택적인 통화 제어에 사용합니다.
  • Google·GitHub 계정 연결은 선택입니다. 해당 서비스의 도구를 쓰는 경우에만 인증 권한을 요청합니다. 기기 캘린더·주소록·전화·SMS·위치·모든 파일 접근 권한은 요청하지 않습니다.
  • 클라우드 모드에서 외부로 보내는 정보와 주소를 안내합니다. 새 API 주소를 설정하면 해당 주소에 대한 안내를 다시 확인합니다.
  • 메일 발송, 일정 등록, 메모 저장, Issue/PR 생성처럼 데이터를 저장하거나 외부 서비스를 변경하는 도구 작업은 실행할 내용을 확인하고 건별로 승인합니다.

권한·연결·외부 전송을 거부하면 관련 기능을 사용할 수 없습니다. 텍스트 대화와 기기 메모에 Google·GitHub 로그인이 필수는 아닙니다. 로컬 AI에는 모델 다운로드, 호환 기기와 충분한 저장 공간이 필요합니다.

4. 보관 기간과 삭제

기기 데이터

대화, 메모, API 키·토큰과 설정·모델은 사용자가 삭제할 때까지 앱의 기기 저장 영역에 보관합니다. 사이드 메뉴에서 채팅방을 삭제하거나, 설정에서 API 키 삭제·계정 연결 해제·다운로드한 모델 삭제를 할 수 있습니다. 개별 메모 삭제 기능은 제공하지 않으며 전체 기기 데이터 삭제로 메모를 지울 수 있습니다.

설정 → 개인정보 → 이 기기의 앱 데이터 모두 삭제를 확인하면 채팅·메모·API 키·토큰·설정·모델을 지우고 앱을 초기화합니다. Android 앱 설정의 저장 공간 삭제 또는 앱 삭제로도 앱 전용 저장 영역을 제거할 수 있습니다.

운영자에게 보낸 신고와 문의

운영자가 받은 신고·문의 이메일과 답변 중 관련 개인정보는 접수일부터 최대 {{AIRCALL_REPORT_RETENTION_DAYS}}일 보관하며, 그 기간 안에 운영자가 메일함과 휴지통에서 영구 삭제합니다. 이 작업은 운영자의 수동 관리이며 앱이 자동으로 삭제하지 않습니다. 더 빠른 삭제는 신고 번호 또는 해당 이메일의 발송 시각을 적어 문의 이메일로 요청할 수 있습니다. 신고를 공개 게시하거나 AI 모델 학습용 자료로 사용하지 않습니다.

발신자의 보낸편지함과 선택한 이메일 제공자의 시스템 로그·백업은 운영자가 직접 삭제할 수 없습니다. 해당 제공자의 보관 및 삭제 정책이 별도로 적용됩니다.

이미 외부로 보낸 데이터

계정 연결 해제는 기기에 저장한 해당 서비스의 토큰·연결 정보를 지우며 Google·GitHub 계정 자체를 삭제하지 않습니다. 서비스의 계정 설정에서 AirCall AI 접근 권한도 취소할 수 있습니다. 이미 발송한 메일·등록한 일정·생성한 Issue/PR·외부 AI에 전달한 데이터는 기기 데이터 삭제로 지워지지 않으므로 해당 서비스의 삭제 절차를 이용해야 합니다.

5. 외부 서비스와 국외 처리

개발자가 사용하는 이메일 접수 서비스는 Google Gmail이며 문의 수신·답변과 메일 저장에 사용합니다. 안내 웹사이트의 호스팅 제공자는 GitHub Pages입니다. Google·GitHub 도구, 클라우드 AI, 모델 다운로드 및 음성 기능은 사용자가 선택한 제공자의 서비스를 직접 호출합니다. 해외 서버에서 처리될 수 있으며 운영 국가·보관 기간·삭제 방법은 선택한 제공자와 계정 설정에 따라 달라집니다.

  • Google 개인정보처리방침: Gmail·Google Calendar·Google 계정 및 Google 음성 서비스를 선택한 경우.
  • GitHub 개인정보처리방침: GitHub 로그인·저장소 도구 및 이 웹사이트의 GitHub Pages 호스팅.
  • Groq 개인정보처리방침: 기본 클라우드 API를 선택한 경우. API의 저장·보관 설정은 사용자의 Groq 계정 설정과 이용 조건도 확인해 주세요.
  • Hugging Face 개인정보처리방침: 로컬 모델 다운로드.

다른 HTTPS API 주소, 음성 서비스나 이메일 앱을 선택했다면 그 제공자의 정책도 확인해 주세요. HTTPS는 전송 구간을 암호화하며 요청을 받는 제공자가 내용을 처리하지 못하게 하는 종단간 암호화는 아닙니다.

6. 보안·로그·백업

대화 기록과 인증정보는 Android Keystore 기반으로 암호화해 앱 전용 저장 영역에 저장합니다. 일반 설정·메모·모델 파일 전체는 암호화하지 않습니다. 앱은 평문 HTTP 연결을 허용하지 않습니다.

도구 이름·작업 종류·성공 여부·시각·지연 시간 등의 실행 정보는 최근 100건의 메모리 기록과 최근 50건의 작업 상태로 관리하며 프로세스 종료 시 사라집니다. 도구 인자·인증 토큰·반환된 개인정보를 작업 알림에 넣지 않습니다. 디버그 빌드에서만 제한된 진단 로그를 기록하며 정식 빌드의 자체 진단 로그는 비활성화합니다.

앱에 광고 SDK, 자체 사용행동 분석 SDK 또는 자체 대화 서버 백업을 포함하지 않습니다. Android의 앱 자동 백업은 비활성화합니다. 기기 제조사·Android의 데이터 이동 동작과 외부 서비스의 시스템 로그·백업은 각 제공자의 정책 및 기기 설정에 영향을 받을 수 있습니다.
