# 원스토어 상품 설명 초안

실제 등록 카테고리·글자수·이미지 규격은 ONEconsole 입력 화면에 맞춥니다.
등록 전 최신 서명 APK의 실제 기능과 문구를 대조하세요.

**앱 이름:** AirCall AI

**요약:** 로컬 모델과 클라우드 API로 나누는 텍스트·음성 AI 대화

## 상세 설명

AirCall AI는 Android에서 글과 음성으로 대화하는 개인 AI 비서 앱입니다.
앱 회원가입 없이 사용할 수 있으며 AI 응답 생성 방식을 직접 선택할 수 있습니다.

- 로컬 모델을 다운로드하고 적용하면 기기에서 AI 텍스트 응답을 생성합니다.
- 사용 중인 AI 서비스의 API 키를 등록하면 클라우드 모델과 대화할 수 있습니다.
- Android 음성 인식과 읽어주기로 음성 대화를 나눌 수 있습니다.
- GitHub·Google 계정을 선택적으로 연결해 저장소 조회, 메일 발송, 일정 조회·등록을 요청할 수 있습니다.
- 기기에 메모를 저장하고 채팅방의 이름을 바꾸거나 기록을 삭제할 수 있습니다.
- 메일 발송·일정 등록 등 변경 작업은 실행 전 내용을 확인하고 승인합니다.
- 라이트·다크·시스템 테마를 선택할 수 있습니다.
- AI 응답 신고와 앱 데이터 삭제 기능을 제공합니다.

## 시작 전에 확인해 주세요

로컬 모델은 별도 다운로드가 필요하며 모델 파일 용량과 기기 메모리를 확인해야 합니다.
모델별 호환성·성능은 기기에 따라 다릅니다. 클라우드 모드에는 사용자 API 키와 인터넷 연결이 필요하며
API 제공자의 이용 요금이 발생할 수 있습니다. 앱에는 광고·앱 내 결제·구독 기능이 없습니다.

음성 기능은 기기의 Android 음성 서비스를 사용합니다. 로컬 AI를 선택해도 음성 서비스가
인터넷을 이용하거나 음성·텍스트를 해당 제공자에게 전송할 수 있습니다.
Google 계정 연결에는 사용 가능한 Google Play 서비스가 필요합니다.
GitHub·Google에 로그인하지 않아도 AI 대화와 기기 메모를 사용할 수 있습니다.

API 키와 로그인 토큰, 대화 기록은 앱 전용 기기 영역에 암호화 저장합니다.
클라우드·외부 도구·음성·신고 기능을 선택하면 기능에 필요한 데이터가 해당 서비스에 전송됩니다.
자세한 내용은 공개 개인정보처리방침과 앱 설정의 개인정보 화면을 확인해 주세요.

AI 답변은 틀릴 수 있습니다. 만 14세 이상을 대상으로 하며 최종 이용 등급은 원스토어 표시를 확인해 주세요.

## 등록 이미지 준비

실제 정식 APK에서 최소 2장, 최대 8장의 스크린샷을 준비합니다. 권장 장면:

1. 예시 텍스트 대화 — 개인정보·실제 계정 데이터 없이 촬영
2. AI 및 모델 설정 — API 키를 표시하지 않음
3. 음성 대화 화면
4. 앱 정보 및 개인정보 화면

원본 앱 아이콘은 `app/src/main/res/drawable-nodpi/aircall_ai_icon.jpg`입니다.
콘솔에서 요구하는 아이콘 규격에 맞춰 제출하고 실제 지원하지 않는 기능을 이미지에 표시하지 않습니다.
